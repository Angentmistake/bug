# HOW TO RUN — Python Team 04

### Requirements
- Python 3 installed
- Google Chrome

### Steps
1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Run:

```bash
python server.py
```

If `python` does not work on Windows, try:

```bash
py server.py
```

4. Wait for the server message.
5. Open Google Chrome.
6. Visit:

`http://localhost:5004`

### If the port is already in use
Run another port manually:

```bash
python server.py 5104
```

Then open `http://localhost:5104`.

### Stop the server
Press `Ctrl + C` in the terminal.
